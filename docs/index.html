Un puente transparente entre tu IA y el editor de Unreal

Los desarrolladores y artistas de Unreal Engine no necesitan cajas negras ni promesas abstractas. Necesitan herramientas fiables que entiendan la escena, respeten la jerarquía del Outliner y no rompan el proyecto.

DBV Unreal AI conecta tu modelo de IA directamente al servidor experimental Model Context Protocol (MCP) de Unreal Engine 5.8 a través de un toolset propio en Python y C++. Antes de ejecutar una sola línea de código, el script se valida estáticamente contra el motor en marcha. Si algo modifica el nivel, tú ves el código completo y decides si autorizarlo. Y si el resultado no te convence, el botón «Deshacer este turno» devuelve el editor exactamente al estado previo.

Del prompt al nivel de Unreal en cuatro pasos

Un flujo de trabajo riguroso diseñado para preservar la estabilidad de tu proyecto en todo momento.

1

Conexión y Múltiples Editores

La aplicación detecta automáticamente las instancias de Unreal Engine abiertas en puertos contiguos (8000, 8001…). La píldora de estado permite alternar entre proyectos activos con verificación de identidad.

2

Preparación con Diff Previo

Si al proyecto le faltan los plugins de MCP o el toolset DBV, el asistente muestra un diff exacto de cada fichero de configuración antes de tocar nada, guarda una copia de seguridad y permite revertir byte a byte.

3

Validación y Aprobación Segura

La IA consulta la escena libremente, pero cualquier modificación aparece en una tarjeta de aprobación con el código Python íntegro. El código se valida contra las APIs reales de tu versión del motor antes de pedir permiso.

4

Generación y Colocación Fotorrealista

Genera mundos completos con World Labs Marble (splats gaussianos .spz y colisión física .glb) o modelos/animaciones con Tripo. «Enviar a Unreal» los importa y los posiciona en el nivel.

Tú eliges el motor de IA. Tu código nunca sale sin permiso.

Sin suscripciones obligatorias ni telemetría oculta. La IA es un colaborador que se adapta a tu infraestructura.

🏠 Modelos Locales (100% Offline)

Conéctate a Ollama, LM Studio o cualquier endpoint local compatible con OpenAI. Ningún byte ni dato de tu proyecto sale jamás de tu ordenador. Funciona completamente sin conexión a internet.

☁️ APIs en la Nube con Llavero Seguro

Utiliza tus claves de Anthropic (Claude 3.5 Sonnet), OpenAI (GPT-4o) o Google (Gemini 2.5/3). Las claves de API se almacenan de forma segura en el llavero de credenciales del sistema operativo, nunca en ficheros de texto plano.

🤖 Agentes de Suscripción (ACP)

Aprovecha los agentes de desarrollo que ya tengas instalados (Claude Code, Codex, Copilot o Gemini CLI con acceso de pago) mediante el protocolo Agent Client Protocol (ACP), compartiendo el contexto de tu proyecto.
