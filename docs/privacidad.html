Política de Privacidad

Última actualización: 28 de octubre de 2026 · Versión 0.2.1

Resumen: DBV Unreal AI no recopila datos personales, no incluye rastreadores ni publicidad, y no envía tus proyectos ni niveles de Unreal Engine a ningún servidor externo. El funcionamiento es 100% local por defecto.

1. Responsable del Tratamiento y Naturaleza del Software

DBV Unreal AI es una herramienta de escritorio de código abierto desarrollada por David Bueno Vallejo y David Bueno Carmona, bajo licencia MIT. La aplicación se ejecuta de forma local en el ordenador del usuario y no dispone de servidores centrales ni bases de datos de recopilación de telemetría.

2. Datos del Editor de Unreal Engine (100% Local)

La comunicación entre DBV Unreal AI y el editor de Unreal Engine 5.8 se realiza exclusivamente en tu propio equipo a través de un servidor local HTTP Model Context Protocol (por defecto en localhost:8000). Tus escenas, niveles, código C++, scripts de Python y assets jamás se envían a ningún servidor externo.

3. Uso de Servicios de Inteligencia Artificial (Opcional)

La funcionalidad de Inteligencia Artificial es completamente opcional y se encuentra desactivada por defecto. Si el usuario decide conectar un modelo de IA, dispone de tres modalidades con implicaciones de privacidad transparentes:

  • IAs Locales (Ollama, LM Studio): Procesamiento íntegramente local en tu hardware. Ningún dato sale de tu equipo.
  • IAs por Suscripción (Agentes CLI): Conectan con herramientas instaladas en tu terminal (como Google Antigravity CLI, Claude Code o GitHub Copilot) utilizando la propia sesión autenticada del usuario.
  • IAs en la Nube con Clave de API: Si introduces una clave privada (Anthropic, OpenAI, Google AI Studio, OpenRouter), esta se almacena únicamente en el almacén seguro de credenciales de tu sistema operativo (Windows Credential Manager / macOS Keychain) y solo se transmiten los prompts que tú envíes explícitamente al proveedor que hayas seleccionado.

4. Servicios de Generación 3D (Tripo3D y World Labs)

Las funciones de generación de mundos o modelos 3D únicamente se comunican con sus respectivas APIs oficiales (Tripo3D y World Labs) cuando el usuario configura voluntariamente su clave de API y pulsa explícitamente en generar. No se envían datos contextuales de tu proyecto sin tu instrucción.

5. Derechos del Usuario y Contacto

Dado que no almacenamos datos personales en servidores remotos, no existe ninguna cuenta ni registro que cancelar. Puedes eliminar cualquier clave de API o conexión en cualquier momento directamente desde la pantalla de configuración de la app. Para cualquier duda o sugerencia, puedes contactarnos a través del repositorio oficial en GitHub.
