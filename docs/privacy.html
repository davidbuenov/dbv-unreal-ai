Privacy Policy

Last updated: October 27, 2026

Summary: DBV Unreal AI does not collect, store on proprietary servers, or share any personal data with third parties. There are no user accounts, no embedded analytics or advertisements, and zero telemetry. Communication with Unreal Engine 5.8 runs entirely on your local machine (localhost). If you connect a cloud AI provider or generate assets via Tripo or World Labs, network requests travel directly from your machine to the respective official APIs, never through any proxy server of ours.

What the application does on your computer

DBV Unreal AI is a native desktop application built with Rust and Tauri v2. It interacts with your running Unreal Engine 5.8 editor instances through the local Model Context Protocol (MCP) server over loopback port 127.0.0.1. Scene queries, static Python validation, and approved executions occur entirely on your local operating system.

Secure Credential Storage

API keys configured in the application (Anthropic, OpenAI, Google Gemini, Tripo 3D, or World Labs) are saved exclusively into your operating system's secure credential vault:

  • Windows: Windows Credential Manager.
  • macOS: Apple Keychain.
  • Linux: Secret Service API / Freedesktop Keyring.

Keys are never written to plaintext config files, tracked in repositories, or displayed back in the assistant UI.

Network Connections

DBV Unreal AI initiates outbound network requests only upon your explicit action:

  • Cloud AI Models (optional): When you configure Anthropic, OpenAI, or Google, messages and selected context are dispatched directly to the official provider endpoints under their respective terms of service. If you use local models (Ollama, LM Studio), nothing leaves your machine.
  • 3D Generation with Tripo (optional): When you confirm and trigger a 3D generation request, the payload is submitted directly to api.tripo3d.ai and output GLB files are downloaded directly into your local library.
  • World Generation with World Labs (optional): When creating environments or polling World Labs Marble jobs, calls communicate directly with api.worldlabs.ai and Gaussian Splats (.spz) and collider meshes (.glb) are downloaded to your disk.
  • GitHub Releases (optional): Triggered only when navigating to external GitHub documentation or release links.

Local Library & Project Memory

All downloaded 3D assets, textures, thumbnails, and project memory files (memory.md and task.md) reside strictly on your local disk or inside your Unreal project repository. You retain full ownership and control to edit, move, or delete them at any time.

Open Source Transparency

The complete source code of DBV Unreal AI is public, open, and auditable under the MIT license at github.com/davidbuenov/dbv-unreal-ai.
