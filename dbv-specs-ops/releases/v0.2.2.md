# DBV Unreal AI v0.2.2 — Notas de la versión

**🇪🇸 Español · [🇬🇧 English](./v0.2.2.en.md)** · 2026-10-29

### Added

- **Descubrimiento real de modelos por CLI, caché de sesión y etiqueta estilo Visual Studio en agentes (REQ-47):**
  - **Consulta en vivo a cada CLI (`ai_list_agent_models`):** `agy models` para Google Antigravity CLI (`Gemini 4 Argon`, `Gemini 3.8 Flash`, `Claude Opus 5.5`, `Claude Sonnet 5.5`, `GPT-OSS 120B`), handshake JSON-RPC `initialize` por `--input-format=stream-json` para Claude Code (`Claude Sonnet 5.5`, `Claude Opus 5.5`, `Claude Fable 5.1`, `Claude Haiku 5.5` con sus `supportedEffortLevels`), y `codex debug models` (con autodetección en `%LOCALAPPDATA%\Programs\OpenAI\Codex\bin`) para OpenAI Codex CLI (`GPT-6-Luna`, `GPT-5.6-Terra`, `GPT-5.6-Luna`).
  - **Resumen visual inmediato al estilo Visual Studio (`.ai-agent-summary`):** cada agente conectado muestra directamente en la lista el modelo y la dificultad activos (p. ej. `Gemini 4 Argon Medium`, `Claude Sonnet 5.5 Medium`, `GPT-6-Luna Medium`) para verlo de un solo vistazo sin abrir el menú de configuración.
  - **Caché de sesión y botón de refresco (`🔄`):** la consulta al CLI se realiza solo la primera vez que se abre «Conectar una IA» en la sesión y se reutiliza en memoria, con un botón `🔄` en el panel ⚙️ para volver a interrogar al CLI bajo demanda.
  - **Propagación ACP completa:** resolución de `<modelo>-<esfuerzo>` y `--effort` en Antigravity CLI, paso de `ANTHROPIC_MODEL` por entorno en Claude Code ACP y `-c model=... -c model_reasoning_effort=...` en Codex ACP, además de notificación `session/set_config_option`.
- **Enlaces oficiales de Microsoft Store:** actualización de `README.md`, `README.en.md`, `docs/index.html` y `docs/en/index.html` con los enlaces directos de descarga en Microsoft Store (`9n5ls7zkgth5` en español e inglés).
