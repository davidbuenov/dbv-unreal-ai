# DBV Unreal AI v0.2.3 — Release notes

**[🇪🇸 Español](./v0.2.3.md) · 🇬🇧 English** · 2026-10-29

The AI connection and its guide are now the same as in every DBV app: those of [`dbv-tauri-starter`](https://github.com/davidbuenov/dbv-tauri-starter) `template-v0.4.0`, where they were tested agent by agent in the real app.

### Fixed

- **Google Antigravity now talks (REQ-49):** the app launched `agy --acp`, which does not exist (the `agy` CLI does not speak ACP). It now connects through its official `agy_acp_server`, from the ACP registry, also looked up in `%LOCALAPPDATA%\agy\acp-server` (Windows) and `~/.local/share/agy-acp-server` (macOS/Linux). With only `agy`, "Connect an AI" says so and links to the instructions.
- **Agent sign-in (REQ-49):** if the agent answers *Authentication required*, the app asks it to `authenticate` with its usual method (*Log in with Google*, *Login with ChatGPT*) and retries; the panel warns that a browser may open.
- **Codex no longer answers "Internal error" (REQ-49):** the adapter is now `@agentclientprotocol/codex-acp` (the `@zed-industries` one stopped at 0.16.0 and does not understand current models); model and reasoning go in `CODEX_CONFIG` instead of `-c` flags.
- **GitHub Copilot (REQ-49):** the `copilot` VS Code puts on the `PATH` is a launcher; the real CLI is preferred and the launcher only counts if it answers. With no CLI, Copilot shows as not installed and "How to install" opens the guide.
- **Assistant panel:** the container has the `ai-panel` class, so header, context and composer no longer shrink and the context chips are no longer cut off.

### Changed

- **Shared AI guide, inside the app (REQ-48):** the *AI Guide* tab of the Help Center (`F1`) shows the full guide shared by every DBV app (local, cloud with a key, subscription with each agent, sign-in, ⚙️ model and reasoning, common problems), offline and with a *Copy* button on each command block. "Unsure which AI to choose or how to install it? Open the guide" and the "How to install" buttons of Antigravity and Copilot open it too, jumping to their section. `docs/IA.md` and `docs/IA.en.md` are generated from the same template; what is specific to Unreal and Tripo goes at the end.
- **Model and reasoning without undocumented flags:** Antigravity gets them through `AGY_ACP_DEFAULT_MODEL` and `session/set_config_option`; no agent receives a flag its adapter does not document anymore.
- **Framework** `dbv-specs-ops` 3.1.0 → 3.2.0.
- **Microsoft Store:** `dbv-unreal-ai_0.2.3.0.msixbundle` package and up-to-date submission documentation (`MICROSOFT_STORE.md` §4; what's new, description and certification notes in `descripcionStore_es.md` and `descripcionStore_en.md`).
- **E2E bench fixed:** it had been failing since v0.2.0 because its simulated backend did not know the project memory (the automatic connection to the editor stayed at "No editor") and a test required an exact list of calls that v0.2.0 extended with read-only queries. It now passes in full, also checks the F1 guide and the About dialog (REQ-45, which had no test), and accepts `E2E_PORT` so it does not clash with a browser open in debug mode on 9333.
