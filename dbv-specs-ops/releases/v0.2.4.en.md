# DBV Unreal AI v0.2.4 — Release Notes

**[🇪🇸 Español](./v0.2.4.md) · 🇬🇧 English** · 2026-10-29

Maintenance release addressing MCP server initialization when installed from the Microsoft Store (MSIX).

### Fixed

- **App MCP server launch in Microsoft Store version (REQ-20):** in Microsoft Store (MSIX) installations, external AI agents (such as Google Antigravity via `agy_acp_server`) encountered a `fork/exec ... dbv-unreal-ai.exe: Access is denied` error when attempting to spawn the MCP subprocess directly against `C:\Program Files\WindowsApps` due to Windows AppModel security restrictions. Added the `appExecutionAliases` declaration in the package manifest (`bundle.config.json`) and Rust backend resolution (`src-tauri/src/lib.rs`) towards the execution alias `%LOCALAPPDATA%\Microsoft\WindowsApps\dbv-unreal-ai.exe` (detected with `symlink_metadata`), allowing any external agent to spawn the app's MCP server cleanly and instantly.
