# DBV Unreal AI v0.2.4 — Notas de la versión

**🇪🇸 Español · [🇬🇧 English](./v0.2.4.en.md)** · 2026-10-29

Versión de mantenimiento que solventa el problema de inicialización del servidor MCP propio en instalaciones procedentes de Microsoft Store (MSIX).

### Fixed

- **Arranque del servidor MCP propio en la versión de Microsoft Store (REQ-20):** en instalaciones desde la Store (paquete MSIX), los agentes de IA externos (como Google Antigravity mediante `agy_acp_server`) recibían un error de `fork/exec ... dbv-unreal-ai.exe: Acceso denegado` al intentar lanzar el subproceso MCP directamente sobre `C:\Program Files\WindowsApps` debido a restricciones de seguridad del AppModel de Windows. Se ha añadido la declaración `appExecutionAliases` en el manifiesto (`bundle.config.json`) y la resolución en backend Rust (`src-tauri/src/lib.rs`) hacia el alias `%LOCALAPPDATA%\Microsoft\WindowsApps\dbv-unreal-ai.exe` (detectado con `symlink_metadata`), permitiendo que cualquier agente externo lance el MCP propio de forma limpia e instantánea.
